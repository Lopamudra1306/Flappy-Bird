# 🐦 Flappy Retro

A retro-style **Flappy Bird clone** built using **HTML5 Canvas, CSS, and Vanilla JavaScript**. The game is lightweight, responsive, and runs directly in the browser without any external frameworks.

## ✨ Features

- 🎮 Classic Flappy Bird gameplay
- 🟢 Multiple difficulty levels (Easy, Medium, Hard)
- 🏆 High score saved using Local Storage
- 🔊 Sound effects with Mute option
- ⏸️ Pause and Resume functionality
- 🌙 Day/Night background cycle
- 📱 Mobile and Desktop support
- 🎨 Pixel-art inspired graphics
- ⚡ Lightweight and fast

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- HTML5 Canvas API
- Web Audio API

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/flappy-retro.git
   ```

2. Open the project folder.

3. Run `index.html` in your browser.

No installation or dependencies are required.

## 🎮 Controls

| Action | Key |
|--------|-----|
| Flap | Space / Click / Tap |
| Pause | P |
